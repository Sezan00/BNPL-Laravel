# 💳 BNPL System (Laravel Backend)

A Buy Now, Pay Later (BNPL) backend system built with Laravel using MVC architecture. This project manages installment-based payments, order tracking, and financial workflows with clean and scalable backend logic.

## 🚀 Features
- Buy Now, Pay Later (BNPL) workflow
- Installment plan management
- Order & payment tracking system
- User-based credit/limit handling
- Dynamic payment scheduling
- Secure backend logic
- RESTful API structure (if used)
- Admin-friendly data management
- Clean MVC architecture

## 🛠 Tech Stack
- PHP
- Laravel (MVC Architecture)
- MySQL
- Blade Templates (if UI used)
- REST API
- Tailwind CSS (optional UI)
- JavaScript (minimal usage)
- Git & GitHub

## 📌 Project Purpose
This project was built to implement a real-world BNPL (Buy Now, Pay Later) system backend, focusing on installment logic, payment flow, and scalable Laravel architecture.

- 👤 User Management
